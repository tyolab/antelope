# Vector V4 — int8 Quantized Vectors Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Store dense vectors as per-dimension scalar int8 (~4× smaller) with a default lossy `replace` mode and an opt-in exact-rerank `exact` mode, transparently to every existing search path.

**Architecture:** A pure quantize/dequantize unit; a new `.qvec` int8 sidecar and an int8 backend inside `ANT_vector_store`; two backend-independent primitives (`reconstruct()`, `score()`) that the exact scan, HNSW, and V2 signing all route through; config-driven flush/compaction/backfill. The float32 path is untouched when quantization is off.

**Tech Stack:** C++ (engine, no heavy deps, STL allowed), GNU make, Node-API addon (JS/TS). Build discipline: this repo has **no header dependency tracking** — after editing any `.h`, run `rm -f obj/*.o` before `make`. `make` auto-discovers `source/*.cpp` and `tests/*.cpp` (a `tests/test_X.cpp` builds to `bin/test_X`).

**Reference spec:** `docs/superpowers/specs/2026-07-07-vector-v4-int8-design.md`

```cpp
/*
	VECTOR_QUANTIZE.H -- per-dimension affine int8 quantization (V4).

	For each dimension d, values are mapped from [min_d, max_d] onto signed
	int8 [-128,127].  Magnitude is preserved per dimension (never per-vector),
	so dot/L2 ranking is unaffected.  A degenerate dimension (max==min)
	reconstructs to exactly min_d.  All functions are pure and deterministic.
*/
#ifndef VECTOR_QUANTIZE_H_
#define VECTOR_QUANTIZE_H_

class ANT_vector_quantize
{
public:
	/* fill mins[dimension]/maxs[dimension] with the per-dimension range over n vectors (row-major) */
	static void compute_ranges(const float *vectors, long long dimension, long long n, float *mins, float *maxs);

	/* quantize one vector[dimension] -> codes[dimension] using mins/maxs */
	static void quantize(const float *vector, long long dimension, const float *mins, const float *maxs, signed char *codes);

	/* reconstruct codes[dimension] -> out[dimension] using mins/maxs */
	static void reconstruct(const signed char *codes, long long dimension, const float *mins, const float *maxs, float *out);
} ;

#endif /* VECTOR_QUANTIZE_H_ */
```

```cpp
/*
	VECTOR_QUANTIZE.CPP
*/
#include <math.h>
#include "vector_quantize.h"

void ANT_vector_quantize::compute_ranges(const float *vectors, long long dimension, long long n, float *mins, float *maxs)
{
long long d, i;
for (d = 0; d < dimension; d++) { mins[d] = 0.0f; maxs[d] = 0.0f; }
if (n <= 0)
	return;
for (d = 0; d < dimension; d++) { mins[d] = vectors[d]; maxs[d] = vectors[d]; }
for (i = 1; i < n; i++)
	for (d = 0; d < dimension; d++)
		{
		float v = vectors[i * dimension + d];
		if (v < mins[d]) mins[d] = v;
		if (v > maxs[d]) maxs[d] = v;
		}
}

void ANT_vector_quantize::quantize(const float *vector, long long dimension, const float *mins, const float *maxs, signed char *codes)
{
long long d;
for (d = 0; d < dimension; d++)
	{
	float range = maxs[d] - mins[d];
	long q;
	if (range <= 0.0f)
		q = 0;					/* degenerate dimension: fixed code, reconstructs to min_d */
	else
		{
		double t = ((double)vector[d] - (double)mins[d]) / (double)range;	/* [0,1] */
		q = (long)floor(t * 255.0 + 0.5) - 128;			/* round-half-up, shift to signed */
		if (q < -128) q = -128;
		if (q > 127) q = 127;
		}
	codes[d] = (signed char)q;
	}
}

void ANT_vector_quantize::reconstruct(const signed char *codes, long long dimension, const float *mins, const float *maxs, float *out)
{
long long d;
for (d = 0; d < dimension; d++)
	{
	float range = maxs[d] - mins[d];
	if (range <= 0.0f)
		out[d] = mins[d];		/* degenerate dimension */
	else
		out[d] = (float)((double)mins[d] + ((double)((int)codes[d] + 128) / 255.0) * (double)range);
	}
}
```

## Task 2: `.qvec` sidecar — writer mode + int8 backend load

**Files:**
- Modify: `source/vector_store.h`, `source/vector_store.cpp`
- Test: `tests/test_vector_store.cpp` (append cases)

**Context:** `.vec` today is `magic("ANTVEC01") | dim i64 | count i64 | presence bitmap | float[count*dim]` (see the header comment in `vector_store.h`). `.qvec` mirrors it with int8 codes plus per-dimension ranges:

```
magic u64 ("ANTQVC01")   dimension i64   count i64
byte[]  presence bitmap ((count + 7) / 8 bytes)
float32 mins[dimension]
float32 maxs[dimension]
int8    codes[count * dimension]     // absent rows still occupy a (zeroed) row
```

The writer buffers all appended float vectors already (`vectors`/`capacity`), so `.qvec` is produced at `finish()` by computing ranges over present rows and quantizing.
